# Datepicker-UI
This project is based on a problem statement from **[roadmap.sh/projects/datepicker-ui](https://roadmap.sh/projects/datepicker-ui)**
The website is a simple datepicker UI using only HTML and CSS. It will not be a functional datepicker, but a static UI component that you can later enhance with JavaScript.

## 🚀 Features
- Simple input with placeholder
- Button with icon
- absolutely positioned elements

## 🎯 Goals of this project
- Creating responsive website component for different screens.
- Practice positioning, layout, and styling techniques in CSS.

## 🌐 Live Demo
[https://kalpana-17.github.io/Datepicker-UI/](https://kalpana-17.github.io/Datepicker-UI/)

## ⚡ Deployment Instructions
### 1. Run Locally
1. Clone the repository by 
 - downloading the zip file [https://github.com/Kalpana-17/Datepicker-UI/archive/refs/heads/main.zip](https://github.com/Kalpana-17/Datepicker-UI/archive/refs/heads/main.zip) and unzip it
 - or use CLI command git clone https://github.com/Kalpana-17/Datepicker-UI.git
2. Open index.html in your browser.

### 2. Deploy on GitHub Pages (Recommended ✅)
1. Push your project to a GitHub repository.
2. Go to Repository Settings > Pages.
3. Under Branch, select main (or master) and / (root).
4. Save, and your site will be live on github pages.
